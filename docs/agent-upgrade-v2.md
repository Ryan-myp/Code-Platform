# Agent 能力升级清单 v2.0

## 本次升级内容

### 1. 新增 Skill：frontend-expert
- **路径**: `~/.hermes/skills/expert/frontend-expert/`
- **定位**: 前端开发专家，专注现代 Web 应用架构与 UI/UX 实现
- **核心能力**:
  - 响应式设计 (Mobile First)
  - 深色/浅色主题系统
  - 流畅动画与交互动效
  - 无障碍访问 (a11y)
  - 性能优化 (Lighthouse > 90)

### 2. 升级 Agent Prompt
| Agent | 升级内容 |
|-------|---------|
| Senior Dev Expert | 全栈开发标准、代码质量规范、完整工作流程 |
| 高级研发助手 | 系统架构设计原则、输出规范、风险评估 |
| 测试助手 | PRD 撰写标准、用户故事模板、验收准则 |

### 3. 新增 Agent 能力标准

#### 后端开发标准
- [ ] RESTful API + OpenAPI 3.0 文档
- [ ] 数据库抽象层，支持多引擎
- [ ] 完整错误处理与日志追踪
- [ ] .env 配置管理

#### 前端开发标准
- [ ] 响应式布局 (320px/768px/1440px)
- [ ] 深色/浅色主题切换
- [ ] 流畅动画 (CSS transitions + transforms)
- [ ] 语义化 HTML + ARIA 属性
- [ ] 首屏加载 < 1s

#### 项目交付标准
- [ ] README.md（项目说明+启动指南）
- [ ] requirements.txt / package.json
- [ ] 一键启动脚本 (start.sh / start.bat)
- [ ] API 接口文档

## 质量检查机制

### Agent 自检验查清单
在生成代码后，Agent 必须自检：

```
□ 功能完整性：核心流程可跑通
□ 错误处理：异常场景有兜底
□ 安全性：无硬编码密钥、SQL 注入防护
□ 兼容性：跨浏览器测试通过
□ 性能：首屏加载 < 2s
□ 文档：README + API 文档齐全
```

### 人工验收检查点
- [ ] 打开浏览器访问 http://localhost:3000
- [ ] 测试所有 CRUD 操作
- [ ] 切换深色/浅色主题
- [ ] 检查移动端响应式
- [ ] 查看控制台无报错

## 使用方式

### 调用方式
```bash
# 通过 Hermes Agent 创建新项目
@Senior Dev Expert，请帮我创建一个 [项目名称]，要求：
- 技术栈：[选择]
- 核心功能：[描述]
- 交付标准：[具体要求]
```

### 预期产出
每个项目应包含：
1. `README.md` — 项目说明与使用指南
2. `backend/` — 后端代码
3. `frontend/` — 前端页面（如需要）
4. `start.sh` — 一键启动脚本
5. `api-docs/` — API 接口文档
