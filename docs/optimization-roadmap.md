## 技术选型

### 沙箱环境
- **方案 A**: Docker 容器隔离（推荐）
- **方案 B**: Python subprocess + 资源限制
- **方案 C**: 虚拟机（过重）

### 知识库
- **方案 A**: SQLite FTS5 全文搜索
- **方案 B**: 集成 Elasticsearch（重量）
- **方案 C**: TF-IDF + 向量检索（轻量）

### 前端增强
- **语法高亮**: Monaco Editor（VS Code 编辑器）
- **文件树**: 自定义 React 组件
- **拖拽上传**: react-dropzone

## 定时任务

已创建 cron job `智能研发平台自动优化`，每日凌晨 2 点执行：
- 检查服务状态
- 同步 Skills 到文件系统
- 生成优化报告
- 清理临时文件

## 验收标准

1. Skills 管理：能创建、编辑、导入、导出 Skill，文件与 DB 同步
2. 知识库：能上传文件、搜索、预览
3. Agent：能看到执行日志、工具调用过程
4. 沙箱：能运行生成的系统，查看输出
